Layout

Files
Left sidebar — browse and open files in the workspace. Right-click for delete and .gitignore options.
Editor
Center pane — CodeMirror 6 editor with tabs, dirty indicator (●), and CTRL+S to save & push.
Panels
Right pane — switchable Preview, AI chat, Logs, and Settings tabs.

Preview

Click ▶ Start preview to start a quarto process in the background. The iframe auto-reloads whenever you save. The status bar at the bottom shows the current preview state.

ProjectRenders the whole project via _quarto.yml.
Follow active fileTracks whichever .qmd file is currently open in the editor.
<file.qmd>Pins the preview to a specific file regardless of what you are editing.

The Logs tab shows quarto's output with ANSI colours. If the preview fails to start, an ⚠ issues badge will appear in the status bar — click it to see the error detail.

Settings

Font sizeEditor font size, 10–22 px.

Word wrapSoft-wrap long lines in the editor.
Auto-saveSaves silently after the configured delay (does not push to GitHub).

Custom snippetsCTRL+Space completions you define yourself — stored in your settings repo.

Settings are persisted in a private GitHub repo named {{ username }}-quarto-ed-settings and restored on every login.

Keyboard shortcuts

Ctrl+SSave the current file and push to GitHub.
Ctrl+SpaceOpen the snippet / autocomplete picker.
Ctrl+FFind & replace panel.
Ctrl+/Toggle line comment.
Alt+↑ / ↓Move current line up or down.
Ctrl+DSelect next occurrence of the current selection.

Open ☰ menu → Edit for all editor commands with their key bindings. ☰ menu → Help → Quickhelp shows the full reference.

Snippets

Press Ctrl+Space to open the picker. Built-in snippets:

r-chunk r-chunk-opts py-chunk bash-chunk callout-note callout-warning callout-tip callout-important tabset columns figure yaml-html yaml-pdf yaml-revealjs yaml-chapter

Add your own under Settings → Custom snippets. Each snippet has a trigger label, a description, and a template with ${placeholder} tab-stops.

Syncing to GitHub

The ↑ Sync button in the top bar commits all staged changes and pushes to the current branch. Ctrl+S also pushes after saving, using the commit message configured in Settings.

⚠ The workspace lives in ephemeral container storage and is lost when the server restarts. Use ↑ Sync or Ctrl+S to push your work to GitHub before closing the browser tab.
